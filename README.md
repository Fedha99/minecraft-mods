# BetterRPGFantasy Modpack 🐉⚔️

Sebuah modpack Minecraft 1.20.1 yang dirancang khusus untuk memberikan pengalaman RPG-Adventure yang mendalam dengan fokus pada combat, leveling, dan looting - **dioptimalkan untuk device low-end!**

## 🚀 Cara Install

### Menggunakan Modrinth Launcher
1. Download [Modrinth Launcher](https://modrinth.com/app)
2. Klik "Browse" → Cari "BetterRPGFantasy"
3. Klik "Install" → Tunggu hingga selesai
4. Play!

### Manual Install
1. Download modpack dari Modrinth
2. Extract file
3. Copy `mods` folder ke `.minecraft/mods/`
4. Jalankan Minecraft dengan Forge 1.20.1

## 🎯 Gameplay Tips

**Combat:**
- Gunakan Epic Fight untuk combat yang lebih smooth
- Pelajari spell dari Iron's Spellbooks
- Upgrade skill di Passive Skill Tree

**Leveling:**
- Auto Leveling akan auto-level character
- Fokus pada quest dan dungeon
- Cari treasure di struktur baru

**Performance:**
- Allocate 4-6GB RAM
- Render distance: 8-12 chunks untuk low-end
- Enable VSync untuk smooth gameplay

## 📝 Requirements

- **Minimum RAM:** 4GB
- **Recommended RAM:** 6-8GB
- **CPU:** Intel i5 / AMD Ryzen 5 atau setara
- **Storage:** 5GB free space
